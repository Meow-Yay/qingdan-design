# 轻单 · 新 UI（v3.0）

一套**单文件、零构建**的界面原型：`index.html` 双击就能用，22 个业务页 + 登录 / 入企 / 打印客户联，亮暗双模。

> 这是设计稿，不是可部署的产品。真正的产品实现按这份稿子逐页落到团队仓库 `TianLingBy/qingdan`（`apps/web`，React）。

## 打开方式

下载 `index.html`，双击用浏览器打开即可（不需要装任何东西、不联网）。

想看某一页，在地址后面加一段：

| 想看 | 地址后缀 |
| --- | --- |
| 工作台 | `index.html#workbench` |
| 登录页 | `index.html?view=login` |
| 登录错误态 | `index.html?view=login-error` |
| 未加入企业（空态） | `index.html?view=no-company` |
| 入企页（未来形态） | `index.html?view=enter` |
| 设置中心（含流星雨） | `index.html#settings` |
| 打印客户联 | 点任意单据行 → 抽屉底部「打印客户联」 |

侧栏可点 22 页；右上角切亮 / 暗；左下角切角色（经理 / 销售 / 仓库）——切角色能直接看出权限差异，比如仓库岗看不到「本月销售总额」那张 KPI。

## 设计语言

- 米白底 + 可换强调色（朱砂 / 靛青 / 松绿 / 藤紫），亮暗跟随系统或手动切
- 全部用 CSS 变量（tokens）驱动，无第三方 UI 库、无图标库（24 枚图标是内联 SVG）
- **四态机制**：`data-state="filled | empty | loading | error"`，四分支常驻 DOM、切换只改属性（列表挂在 `tbody`，面板挂在容器上）
- **权限**：24 个功能域 × 11 个动作的权限矩阵；页面里所有「能不能做」都按权限点判断，不按职位
